# PurpleBeanGaming branding

The official product name is **PurpleBeanGaming**. Use **Purple Bean Gaming** in prose and **PURPLE BEAN / GAMING** for the compact wordmark. Branding is centralized in `lib/config.ts`; user interfaces should import that configuration rather than introduce new product-name literals.

The approved bean-with-headphones mark is stored at `public/brand/purple-bean-mark.png`. Keep stable technical identifiers unchanged, including migration history, database identifiers, development slugs and domains, environment names, worker names, and the historical rating version `draftgg_rating_v1`.

Voice is concise, confident, welcoming, and operational. Avoid cartoon copy, exaggerated esports jargon, neon/cyberpunk language, and claims unsupported by real application data.

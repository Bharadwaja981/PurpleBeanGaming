# Public privacy policy

Public player slugs are stable, hashed identifiers and do not reveal auth UUIDs. Region, MMR history, Steam, and Discord visibility default to false. Draft snapshots include region only when its public flag was enabled at snapshot time; Steam and Discord are never included in Phase 05 projections.

Public projections exclude email, auth IDs, evidence, appeals, rating reviews, declared/verified rating internals, scouting, private notes, rejected-bid metadata, security events, and raw audit payloads.

Public live responses expose accepted bids only. Feasibility details, safe-range internals, actor IDs, request IDs, and raw event payloads remain organizer-only. The public health object is deliberately limited to a status code and plain-language summary.

Only completed draft-time MMR snapshots are used for historical analytics. Privacy changes affect future snapshots and current profile presentation without mutating already-published historical facts.
